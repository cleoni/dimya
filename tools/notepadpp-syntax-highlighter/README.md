How to Install in Notepad++

**Method 1: Via the Notepad++ UI (Easiest)**
Open Notepad++.
In the top menu, go to Language → User Defined Language → Define your language...
Click the Import... button.
Select dimx_udl_notepadpp.xml (or dimx_udl_notepadpp_dark.xml if using Dark Mode).
Restart Notepad++ (or reopen your .dxw file).


**Method 2: Direct File Placement**

Copy either file into your Notepad++ user defined languages folder:

text
%APPDATA%\Notepad++\userDefineLangs\dimx_udl_notepadpp.xml

Restart Notepad++, and any .dxw or .dxs file opened will highlight automatically.
